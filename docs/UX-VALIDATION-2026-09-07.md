# UX 重构实施与实机验收记录

本记录对应 [重构规格](UX-REDESIGN-SPEC-2026-09-07.md) 和 [48 项审查](UX-AUDIT-2026-09-06.md)。当前仍在实施与验证，不能据此认定 35 条验收全部通过。

## 验证环境与证据边界

- 实际设备：Apple M3 Max，macOS 27；真实 GPUI 原生桌面窗口，使用系统文件选择器和应用快捷键操作。
- 使用单独的验证应用包、配置与课程库：`/tmp/course2md-ux-validation`。不替换已安装的正式应用，不修改用户已有课程或服务配置。
- 视频、字幕和服务返回均为合成测试资料。桌面应用、工作进程、字幕解析、ffmpeg、内部发布及导出运行真实实现。
- 本地故障服务监听 `127.0.0.1:8769`，可分别返回有效正文、错误格式、401、429、接收后断开连接及延迟响应。请求日志仅保留模型、用途、字节数与媒体类型等验证字段。
- 在线分集、字幕和迟到响应由隔离应用的 `BV1UX*` 受控提取器提供，其余 URL 仍由安装的 yt-dlp 读取。受控依赖验证不能作为真实 Bilibili 平台连通性证据。
- 截图与对应原生可访问性树保存在测试目录的 `screenshots` 中。AX 树检查和实际 VoiceOver 操作分别记录，互不替代。
- 自动测试用于核验持久化、版本保护和网络边界，不代替页面上的实机观察。

复刻过程实机曝光并修复了四个存量缺陷（均为本轮之前的代码引入，此前从未被实机触及；复测证据即上表）：

1. **截断无省略号且撕裂字形**：本仓库 GPUI 的 `line_clamp` 只限制行数，末行越界硬裁。全库截断点改为 `text_ellipsis` 配方（复刻注意事项见 ux-mock README）。
2. **卡片底栏 ⋯ 被挤出**：gpui-component Button 的 `flex_1` 在含长文本 child 时实测失效；chip 改为布局方显式计算 `max_w`。
3. **库根未注册导致分组被静默禁用（17d49d1）**：有工作区记录时启动库根指向 `desktop-local-library`，与已注册库根不符，`library_error` 常设且无界面提示，「按文件夹」被禁用。现回退到工作区首个可读位置。
4. **减少动态效果下分组内容恒不可见（9f5dda3）**：MotionReveal 首帧零高、依赖后续帧测量，该路径自 eced30b 引入起在验证环境从未可达（被缺陷 3 的门控掩盖）。`disclosure` 在 reduce-motion 下直接渲染终态；非 reduce-motion 的展开/收起动画本轮只做了交互抽查。

边界：封面纯蓝块是合成夹具的缩略图数据，不是版式问题；200% 中等宽度下 chip 只剩「20…」属 mock 既定取舍（信息量少但不破版）；阅读页、生成页、设置页的 200% 几何未在本轮范围；缺陷 3 修复前分组视图在本环境从未渲染过，不能由本轮推定其历史行为。

## 重现入口

测试脚本：`desktop/scripts/ux_fixture.py` 和 `desktop/scripts/ux_ytdlp.py`。

```sh
python3 desktop/scripts/ux_fixture.py prepare
python3 desktop/scripts/ux_fixture.py serve
# 两个 debug 可执行文件构建完成后，在另一终端打包隔离应用：
python3 desktop/scripts/ux_fixture.py bundle --label v2
```

`prepare` 创建合成视频/字幕并将服务响应重置为有效结果。需要保留正在进行的故障场景时不要重复调用。`bundle` 只复制已构建的本机程序，不代替构建或测试。测试服务仅用于合成内容。
