# 原生截图索引

本目录保留逐轮设计问题与最终修复的真实窗口截图。文件采用 JPEG 原始内容，没有重新绘制或修改界面。

- `01`–`28` 与 `theme-*`：design03，普通窗口。包括 10 套配色、设置和完整生成/阅读流程。部分截图仍展示随后修复的缺陷。
- `30`–`33`：design04，普通窗口。证明重启主题保持、卡片圆角及阅读比例；图片页脚在下一轮继续修复。
- `37`、`38`：design05，860×620，独立浅色/深色偏好与双列外观布局。
- `40`–`52`：design06，860×620，最终窄窗布局和后台重绘修复。`49` 是实际读取中，`50` 是读取完成。
- `54`、`55`：已安装的 optimized release 预览版，正常初始窗口；工作台和实际构建提交信息。
- `56`、`57`：同一预览版通过原生窗口按钮放大与恢复。

早期名称中带有 `final` 的图片表示当时轮次，不替代后续的最终验收。明确结论见上一级 README 和三份逐页审查报告。
