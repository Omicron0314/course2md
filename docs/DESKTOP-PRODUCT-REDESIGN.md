# 课程库与账号流程设计

本轮先让不带项目历史上下文的设计子代理提出使用流程，再实施。参考 better-layout 的共享对齐边、渐进披露，以及 better-ui 的可中断动效原则。以下尺寸是项目约定，不是平台规范的硬性数字。

## 信息与操作

- 课程库是默认入口；添加课程是标题行右侧的主操作。
- 搜索、按文件夹分组、列表／卡片切换常驻同一工具栏。展示偏好保存，不触发磁盘扫描。
- 默认列表；卡片按窗口可用宽度计算列数。两种视图使用相同课程、归属和筛选结果。
- 一个课程属于一个逻辑文件夹。移动不移动输出文件；删除文件夹保留课程，归入未分类。
- 分组标题与课程区域对齐，包含名称、数量、展开状态。进入具体文件夹可重命名或删除。
- Bilibili 长期入口在设置的连接账号页；粘贴 Bilibili 链接时显示账号状态与登录入口。
- 二维码对话框分别表达获取、等待扫码、等待手机确认、过期、失败、成功。取消使当前代次失效，迟到的请求不能保存凭据。
- 登录后的重新读取只恢复同一来源草稿，不自动启动转换。

## 布局与动效

- 侧栏 224，主区域左右留白 24，普通控件 36 高、14 字号。
- 表单输入与同排动作使用同一高度。卡片标题保留两行空间，归属动作固定在底部。
- 文件夹展开使用可中断 200ms cubic-bezier(0.2,0,0,1)，保持内容与相邻组的空间关系。
- 设置标签指示条以 180ms 相同曲线移动；取消原先整个页面的淡入闪烁。
- 二维码沿用组件原生非线性对话框入场和焦点约束。关闭立即取消；不宣称有反向退场动画。
- 减少动态效果时直接呈现最终状态。

## 对比度基线

采用 [WCAG 2.2 文本对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) 的普通文本至少 4.5:1 作为桌面配色验收目标。以下从 theme.rs 的实色计算，不代表完整无障碍合规认证。

| 组合 | 对比度 |
| --- | --- |
| 正文 / 白色内容面 | 14.42:1 |
| 辅助文字 / 白色内容面 | 7.80:1 |
| 辅助文字 / 侧栏 | 6.53:1 |
| 白字 / 主色 | 6.12:1 |
| 控件边界 / 白色内容面 | 4.94:1 |
| 主色文字 / 浅蓝选中底 | 5.36:1 |
