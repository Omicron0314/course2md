# 全产品审查与修正 · 2026-09-09

状态：进行中。此前的通过结论已在[审查失误复盘](UX-REVIEW-FAILURE-2026-09-09.md)撤回。本报告不把已有截图、实现或测试记录自动视为新的验收。

## Goal 与范围

从首次使用、输入视频、处理中断与恢复、任务结果、阅读和找回内容，到全部设置，重新判断页面用途、信息取舍和操作归属。统一的是对象关系、视觉层级和反馈规则；不是把所有内容装进同一种组件。保留用户数据、既有默认配置与配色、原生窗口和键盘行为。专项无障碍审计不在本次范围。发布标签及线上资产不变。

修正顺序：独立初审 → 更新不合适的设计规则 → 共享布局与流程实现 → 原生实际操作 → 交叉视觉复核 → 修正剩余问题 → 分项提交和安装预览。主代理负责最终整页判断；实现某一区域的人不能成为该区域唯一的最终审查者。

## 共同原因与新的审查标准

1. **以内部实现组织页面。** 计划、生成阶段、日志、模型文件名获得了比视频身份和可读结果更高的地位。审查先问这些信息能否帮助用户作决定，再决定是否呈现。
2. **把单个控件整齐误认为整页合理。** 标签、控件、说明和关联动作各自对齐，却没有共同的边界。审查以一个设置、一个服务、一份模型资源、一条任务为单位。
3. **机械套用项目规则。** 信息框、胶囊、粗体和图标只是表达手段。每句话加框会打断阅读；每个字段加图标也不能建立主次。规则自身接受审查，不因写成 skill 就被当作正确。
4. **把编译和截图数量当成验收。** 静态画面不证明搜索范围、晚响应、失败恢复、模型准备或停止动作成立。流程需实际触发，动效需实际观察；未访问的状态不得标为通过。
5. **修改者缺少外部挑战。** 本轮保留独立初审，并在原生截图后轮换区域复核。主代理仍需判断完整页面，不把“审查者没有新问题”当作自动通过。

相关原则已进入 [course2md-design](../.agents/skills/course2md-design/SKILL.md) 和[构图审查规则](../.agents/skills/course2md-design/references/composition-review.md)。Material 离线来源保留；Apple HIG 的布局、设置、输入和搜索指导通过官方发布的文档数据核对，并明确区分官方原则与项目适配。
