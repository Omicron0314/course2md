# 全产品审查与修正 · 2026-09-09

状态：本轮审查、修正和本机预览交付已完成。此前的通过结论已在[审查失误复盘](UX-REVIEW-FAILURE-2026-09-09.md)撤回。以下结论只覆盖列明的版本、实际操作和证据，不表示用户已经验收，也不表示所有环境都无缺陷。

## Goal 与范围

从首次使用、输入视频、处理中断与恢复、任务结果、阅读和找回内容，到全部设置，重新判断页面用途、信息取舍和操作归属。统一的是对象关系、视觉层级和反馈规则；不是把所有内容装进同一种组件。保留用户数据、既有默认配置与配色、原生窗口和键盘行为。专项无障碍审计不在本次范围。发布标签及线上资产不变。

修正顺序：独立初审 → 更新不合适的设计规则 → 共享布局与流程实现 → 原生实际操作 → 交叉视觉复核 → 修正剩余问题 → 分项提交和安装预览。主代理负责最终整页判断；实现某一区域的人不能成为该区域唯一的最终审查者。

## 共同原因与新的审查标准

1. **以内部实现组织页面。** 计划、生成阶段、日志、模型文件名获得了比视频身份和可读结果更高的地位。审查先问这些信息能否帮助用户作决定，再决定是否呈现。
2. **把单个控件整齐误认为整页合理。** 标签、控件、说明和关联动作各自对齐，却没有共同的边界。审查以一个设置、一个服务、一份模型资源、一条任务为单位。
3. **机械套用项目规则。** 信息框、胶囊、粗体和图标只是表达手段。每句话加框会打断阅读；每个字段加图标也不能建立主次。规则自身接受审查，不因写成 skill 就被当作正确。
4. **把编译和截图数量当成验收。** 静态画面不证明搜索范围、晚响应、失败恢复、模型准备或停止动作成立。流程需实际触发，动效需实际观察；未访问的状态不得标为通过。
5. **修改者缺少外部挑战。** 本轮保留独立初审，并在原生截图后轮换区域复核。主代理仍需判断完整页面，不把“审查者没有新问题”当作自动通过。

相关原则已进入 [course2md-design](../.agents/skills/course2md-design/SKILL.md) 和[构图审查规则](../.agents/skills/course2md-design/references/composition-review.md)。Material 离线来源保留；Apple HIG 的布局、设置、输入和搜索指导通过官方发布的文档数据核对，并明确区分官方原则与项目适配。

## 被独立复核推翻并继续修正的判断

- 第一轮“已有部分结果卡足够清楚”被否定：三层状态重复、401 仍给旧配置重试、工作台被历史任务占据。改为可读结果优先，具体失败就近恢复，已提交且未修改的终态输入返回新表单。
- “只要有搜索框就能找到”被否定：首个命中被工具栏盖住，图库搜索跳错视图。修正实际文字布局测量、正文和图库分别定位；窄窗再减少固定工具栏高度。
- “图片与文字并排放下就可用”被否定：200% 字号下图片剩 1%。小窗口改为图片/文字两种明确模式，前后翻页与返回动作保留。
- “服务保存后就是修复完成”被否定：默认仍绑定旧版本没有就近入口；仅保存说明与实际提交矛盾。保存、测试、开始补做、用于以后生成分别描述其后果，并用真实请求及文件比较验证。
- “只把日志折叠即可”被否定：普通完成仍把流程细节放在主要阅读位置。正常结果去掉成功事实表和原始日志入口，异常保留必要解释和技术详情。
- “读完新版就能直接替换当前页”被独立复核指出边界：慢读期间的最新位置和仍打开的大图不能丢失。原版位置在替换前再次捕获；打开查看器会停止自动跟随，保留旧正文和弹层，后续通过已有新版入口打开。查看器完成前后及定位旧正文再开新版已原生验证；人为慢磁盘读入期间滚动、读入期间开图再关闭仍只由静态与边界测试覆盖。
- “导出失败意味着笔记不完整”被否定：可选文件和可读内容是不同结果。内容质量只依据正文、截图、校对和摘要；只补导出保留原版本并直接找到文件。

## 验证与性能边界

v9 原生桌面测试：**223 passed，0 failed，3 ignored**。构建使用真实 Apple 模块，没有 `COURSE2MD_NO_APPLE`；测试不是视觉验收。新增测试围绕冻结计划、作用范围、迟到响应、部分结果、导出文件可达性、搜索定位等行为，没有通过检查 padding 数值代替设计判断。

已观察的受控转换、设置和阅读没有复现卡死。调试性能记录中，一段普通窗口运行的绘制 p50/p95/p99 为 21.5/45.2/56.8 ms；13 次输入样本均低于 100 ms。模型准备期间 16963 次绘制的 p50/p95/p99 为 12/15.2/21.8 ms。样本数、调试构建、窗口和动画状态都影响结果，不能据此宣称稳定 60 fps 或所有性能问题解决；真实长课程、长时间负载和其它硬件仍需后续观察。性能采样仅在显式 feature 下启用，交付 release 不包含它。
