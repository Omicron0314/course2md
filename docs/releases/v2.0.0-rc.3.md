# v2.0.0-rc.3：设置与引导的统一版式，Linux/Windows 凭据修复

这是 **2.0 的第三个候选发布版（RC3）**。本版重做设置页、首次引导与课程库控制的版式，把保存的 AI 服务从「停用」改为真正的「删除」，并修复 Linux/Windows 桌面端无法保存 API Key 的问题。GitHub Latest、默认 Homebrew 包和 AUR 稳定包继续提供稳定版；试用 RC3 请使用本页附件或独立 RC 通道。

## 相比 RC2

- **Linux/Windows 凭据修复**：桌面端此前只能把 API Key 存进 macOS 钥匙串，Linux/Windows 保存服务会直接失败。现在优先使用系统钥匙串（Linux Secret Service / Windows 凭据管理器），不可用时回退到 0600 权限的文件存储，与 CLI 的 `config.toml` 策略一致。
- **服务管理**：保存的 AI 服务使用「删除…」（带确认对话框）取代「停用」：一并移除版本、草稿、凭据与默认绑定；独立的删除标记确保恢复旧配置备份也不能复活派发，已经发出的请求结果仍会保存。
- **设置页版式**：应用页的运行检查、默认识别模型与缓存并入共享设置卡片与紧凑状态行；生成笔记页移除突兀的说明句；诊断详情就地展开。
- **首次引导**：引擎选择平铺展示（不再有 收起引擎/更换引擎）；llama.cpp 在本机存在即可用，不再依赖 `--list-devices` 成功；已保存的 API Key 字段显示掩码占位而不是空白框。
- **课程库与任务页**：全部笔记/文件夹筛选与列表/卡片布局改为一层选项；任务页标题与摘要获得与其他页面一致的边距。
- **下载反馈**：模型下载在设置、引导与任务进度中统一显示带标签的速度与预计剩余时间。
- **内部清理**：桌面端项目代码告警清零；渲染期不再进行文件系统探测；移除死代码与一次性源码守卫测试；新增 `just install` 一键本机测试安装。

## 下载桌面应用

GUI 包含同版本 CLI 引擎，无需另装 CLI。

| 平台 | 安装包 | 使用方式 |
| --- | --- | --- |
| macOS Apple Silicon，macOS 15+ | [DMG](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.3/course2md-gui-macos-arm64.dmg) | 退出旧应用，将完整 `course2md.app` 放入「应用程序」 |
| Windows x64 | [桌面 ZIP](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.3/course2md-desktop-windows-AMD64.zip) | 完整解压，打开 `course2md-desktop.exe`，保留同目录的引擎 |
| Linux x64 | [桌面 tar.gz](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.3/course2md-desktop-linux-x86_64.tar.gz) | 完整解压，运行 `./course2md-desktop`；预编译包基于 Ubuntu 24.04 |

处理视频需要 ffmpeg/ffprobe，在线视频还需要 yt-dlp。Homebrew 会安装这些依赖；手动安装请参阅 [安装指南](https://github.com/mizorewww/course2md/wiki)。Intel Mac 和 Linux ARM64 提供独立 CLI，暂不提供预编译 GUI。

## Homebrew RC 通道

首次安装：

```sh
brew update
brew install --cask mizorewww/tap/course2md-gui@rc
```

已有稳定版或 alpha/旧 RC 的用户，先退出应用，再卸载原 cask（`course2md-gui`、`course2md-gui@alpha` 或旧 RC），然后安装 RC cask。卸载时不要加 `--zap`，以保留用户数据。手动安装过的应用可先移出「应用程序」留作备份。

后续更新使用 `brew upgrade --cask course2md-gui@rc`。独立 CLI 也有 RC 通道，默认不替换终端中的稳定版命令：

```sh
brew install mizorewww/tap/course2md-rc
"$(brew --prefix course2md-rc)/bin/course2md" --version
```

独立 CLI 附件覆盖 macOS ARM64/x86_64、Linux ARM64/x86_64 和 Windows x64。手动安装 Apple Silicon CLI 时，还需下载本页 `mlx-macos-arm64.metallib`，改名为 `mlx.metallib` 并放在 CLI 同一目录；Unix 可执行文件需赋予执行权限。

## 升级与验证范围

- 从 RC2 升级可直接覆盖安装，保留配置、课程输出及模型缓存。此前被「停用」的服务记录会在首次打开时清理为已删除状态。
- 本版改动经 macOS 本机回归验证（227 项桌面测试通过），Linux/Windows 凭据修复经 Arch Linux + Niri（Wayland）实机验证；三个平台的桌面 release 测试、打包检查与 CLI 构建由发布流程执行。
- Windows/Linux 原生视觉、其他硬件的识别、真实第三方服务和账号网络组合，以及长时间高负载使用仍需进一步试用；macOS 的验证结果不代表所有平台和场景均已覆盖。

启动后在「设置 → 应用」确认版本 `2.0.0-rc.3`；CLI 使用 `--version` 确认。反馈问题时请附系统、版本、复现步骤和已脱敏的诊断信息。

## English

**2.0 RC3** restyles the settings pages, onboarding engine choices and library controls around shared cards and one-level choice groups, replaces the half-hidden "disable" for saved AI services with a real **delete** (versions, drafts, credentials and defaults are removed; a standalone marker keeps dispatch blocked even if an older backup is restored), and fixes API Key saving on Linux/Windows — the desktop app now prefers the system keyring (Secret Service / Windows Credential Manager) and falls back to a 0600-permission file, matching the CLI's `config.toml` policy. Model downloads show labeled speed and ETA everywhere, and the desktop codebase builds with zero warnings of its own.

Use the platform assets above or the independent Homebrew `course2md-gui@rc` and `course2md-rc` channels. Stable packages remain unchanged. macOS (227 desktop tests) and Arch Linux + Niri (credential save) were verified directly; Windows/Linux visuals, other recognition hardware, live third-party services and sustained-load scenarios still need broader testing.
