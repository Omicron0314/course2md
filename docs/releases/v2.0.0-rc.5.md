# v2.0.0-rc.5：Ollama 与 Codex 订阅登录，修复「200 次请求无产出」静默失败

这是 **2.0 的第五个候选发布版（RC5）**。本版引入插件化登录框架并接入两种新 AI 服务登录方式——本地 Ollama 与 ChatGPT 订阅（Codex）；同时修复两个导致「请求发出去却拿不到笔记」的真实缺陷：语音端点持续返回空文本时的静默失败（约 200 次请求全部记为「静音」），以及纯文本校对按画面 Section 切片造成的请求放大。GitHub Latest、默认 Homebrew 包和 AUR 稳定包继续提供稳定版；试用 RC5 请使用本页附件或独立 RC 通道。

## 相比 RC4

- **插件化登录框架**：登录方法实现统一 trait 后在注册表加一行即可接入 `--login/--logout`，后续新增登录方式无需改动派发与配置代码。
- **`--login ollama`**：发现本机 Ollama 服务、列出可用模型并写入配置，本地模型零密钥直接使用。
- **`--login codex`**：导入 codex CLI 的 ChatGPT 订阅登录态（读取 `~/.codex/auth.json`，token 自动刷新并回写）；未安装 codex CLI 或登录态失效时，自动回退到浏览器 PKCE 授权。桌面端「设置 → AI 服务」同样支持 Ollama 本地与 Codex 订阅登录。
- **修复「200 次请求无产出」**：当语音端点对每个分片都返回 HTTP 200 空文本时，旧逻辑把空结果当「静音」继续发请求，全程无报错也不产出笔记。现在连续空分片提前熔断并明确报错；空结果先缓冲不落 checkpoint；全空的转写缓存不再毒化后续重跑（加载时丢弃并重新识别）；润色失败时结果消息带失败计数与首个错误原因，而不是一句笼统的「失败」。
- **修复校对请求放大**：纯文本 LLM 校对此前按画面 Section 切片，画面切换频繁时请求数被放大十几倍；现跨 Section 统一按 20 条语音合并批次。
- **CLI 新增 `--summarize` / `--no-summarize`**：命令行直接开关 AI 总结；单独使用 `--summarize` 可跳过逐句校对、快速生成视频总结。
- **桌面端跟进修复**：引导页内容超出面板高度时改为滚动而非压缩；Codex/Ollama 接入经两轮运行中应用评审的 12 项发现全部修复（登录失败区分「未登录」与其他错误、模型目录刷新、状态文案等）。

## Homebrew RC 通道

首次安装：

```sh
brew update
brew install --cask mizorewww/tap/course2md-gui@rc
```

已有稳定版或 alpha/旧 RC 的用户，先退出应用，再卸载原 cask（`course2md-gui`、`course2md-gui@alpha` 或旧 RC），然后安装 RC cask。卸载时不要加 `--zap`，以保留用户数据。手动安装过的应用可先移出「应用程序」留作备份。

后续更新使用 `brew upgrade --cask course2md-gui@rc`。独立 CLI 也有 RC 通道，默认不替换终端中的稳定版命令：

```sh
brew install mizorewww/tap/course2md-rc
"$(brew --prefix course2md-rc)/bin/course2md" --version
```

独立 CLI 附件覆盖 macOS ARM64/x86_64、Linux ARM64/x86_64 和 Windows x64。手动安装 Apple Silicon CLI 时，还需下载本页 `mlx-macos-arm64.metallib`，改名为 `mlx.metallib` 并放在 CLI 同一目录；Unix 可执行文件需赋予执行权限。

## 升级与验证范围

- 从 RC4 升级可直接覆盖安装，保留配置、课程输出及模型缓存。Codex 凭据独立存放在配置目录的 `auth/codex.json`（0600 权限），不改动 codex CLI 自身文件。
- 本版改动经 macOS 本机回归验证：引擎 173 项、桌面 229 项测试全部通过；引擎 clippy 零告警（CI 以 `-D warnings` 为门槛），桌面端本次改动涉及的代码 clippy 无新增告警（其余为 vendored GPUI 依赖与未触动的既有代码中的历史告警）；Codex 导入登录与真实润色、Ollama 登录与润色、校对请求合批（多 Section 合并为单次请求）均完成端到端验证；桌面端登录链路经运行中原生应用的两轮操作验证。
- 已知验证边界：Codex 浏览器 PKCE 授权全流程未在真实浏览器中完整点击通过（PKCE 向量、回调解析与 state 校验由单元测试覆盖）；Codex 长任务中的 token 自动刷新只验证了「导入即过期→现场刷新」分支；Windows/Linux 原生视觉、其他硬件识别与长时间高负载使用仍需进一步试用。

启动后在「设置 → 应用」确认版本 `2.0.0-rc.5`；CLI 使用 `--version` 确认。反馈问题时请附系统、版本、复现步骤和已脱敏的诊断信息。

## English

**2.0 RC5** adds a pluggable login framework and two new AI-service sign-in methods — local Ollama (service discovery and model selection, no API key) and ChatGPT-subscription Codex (imports the codex CLI login state with automatic token refresh, falling back to browser PKCE authorization when the CLI login is missing or expired; also available in the desktop settings). It also fixes two defects that produced requests without notes: a speech endpoint returning HTTP 200 with empty text for every shard used to be logged as "silence" forever (about 200 requests, no error, no notes) — empty shards now trip a circuit breaker with a clear error, empty results no longer poison checkpoints or the transcript cache, and polish failures report the failure count plus the first underlying error. Plain-text proofreading no longer amplifies requests by picture Section (batches now merge across Sections at 20 utterances), and the CLI gains `--summarize`/`--no-summarize`, including a summarize-only fast path.

Use the platform assets above or the independent Homebrew `course2md-gui@rc` and `course2md-rc` channels. Stable packages remain unchanged. Verified on macOS (173 engine + 229 desktop tests; the engine is clippy-clean under CI's `-D warnings` gate, and the desktop changes introduce no new clippy warnings — remaining warnings live in vendored GPUI sources and untouched pre-existing code; real end-to-end Codex and Ollama logins and polish runs, and two rounds of in-app desktop verification). Not yet covered: a full real-browser PKCE run (unit-tested only), Codex token refresh under long-running tasks, and Windows/Linux visuals, other recognition hardware and sustained-load scenarios.
