# v2.0.0-rc.1：直接转换、首次引导与阅读恢复

这是 **2.0 的第一个候选发布版（RC1）**。本版集中改进从首次配置、视频转换到阅读与失败恢复的完整桌面流程。GitHub Latest、默认 Homebrew 包和 AUR 稳定包继续提供稳定版；试用 RC1 请使用本页附件或独立 RC 通道。

## 相比 alpha.1

- **添加视频即可开始转换**：移除草稿管理、计划确认和独立完成页。当前跟随的转换完成后直接打开正文；后台任务完成时保留用户当前页面。
- **四步首次使用引导**：选择默认识别方式与模型，配置和检查 AI 服务，可选登录 Bilibili，再准备识别模型。可跳过可选步骤，并从设置重新开始。引擎卡片显示本机可用状态，模型下载和加载验证分别反馈。
- **设置和状态反馈**：按设置对象统一标签、控件、帮助与操作的布局，整理应用、账号、服务、模型和存储页面。提供十种主题配色、界面缩放和可关闭的状态动效。
- **可靠的恢复范围**：部分结果可以先阅读，再补做失败部分；单独重试导出不会重跑识别或改写正文。补做使用原任务配置，全局默认值通过独立操作明确修改。
- **阅读连续性**：补做完成时，仍在阅读原版本的用户可接续新版；离开页面或打开图片查看器后不会被后台结果打断。阅读位置按版本保留。
- **阅读与导出**：改进正文和截图搜索、宽屏目录、窄窗工具栏、截图卡片及图片查看布局；HTML 导出包含对应图片，应用中可打开导出文件夹。
- **服务与存储**：从服务地址读取模型列表，编辑配置后使旧检查结果失效；改进离线课程库、文件读取失败、迁移和保存失败时的恢复入口。
- **渲染与响应**：修复 macOS 同步重绘循环与 Metal drawable 生命周期，移出页面渲染中的磁盘检查；性能采样通过显式构建选项启用。

## 下载桌面应用

GUI 包含同版本 CLI 引擎，无需另装 CLI。

| 平台 | 安装包 | 使用方式 |
| --- | --- | --- |
| macOS Apple Silicon，macOS 15+ | [DMG](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.1/course2md-gui-macos-arm64.dmg) | 退出旧应用，将完整 `course2md.app` 放入「应用程序」 |
| Windows x64 | [桌面 ZIP](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.1/course2md-desktop-windows-AMD64.zip) | 完整解压，打开 `course2md-desktop.exe`，保留同目录的引擎 |
| Linux x64 | [桌面 tar.gz](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.1/course2md-desktop-linux-x86_64.tar.gz) | 完整解压，运行 `./course2md-desktop`；预编译包基于 Ubuntu 24.04 |

处理视频需要 ffmpeg/ffprobe，在线视频还需要 yt-dlp。Homebrew 会安装这些依赖；手动安装请参阅 [安装指南](https://github.com/mizorewww/course2md/wiki)。Intel Mac 和 Linux ARM64 提供独立 CLI，暂不提供预编译 GUI。

## Homebrew RC 通道

首次安装：

```sh
brew update
brew install --cask mizorewww/tap/course2md-gui@rc
```

已有稳定版或 alpha 的用户，先退出应用，再卸载原 cask（`course2md-gui` 或 `course2md-gui@alpha`），然后安装 RC cask。卸载时不要加 `--zap`，以保留用户数据。手动安装过的应用可先移出「应用程序」留作备份。

后续更新使用 `brew upgrade --cask course2md-gui@rc`。独立 CLI 也有 RC 通道，默认不替换终端中的稳定版命令：

```sh
brew install mizorewww/tap/course2md-rc
"$(brew --prefix course2md-rc)/bin/course2md" --version
```

独立 CLI 附件覆盖 macOS ARM64/x86_64、Linux ARM64/x86_64 和 Windows x64。手动安装 Apple Silicon CLI 时，还需下载本页 `mlx-macos-arm64.metallib`，改名为 `mlx.metallib` 并放在 CLI 同一目录；Unix 可执行文件需赋予执行权限。

## 升级与验证范围

- 升级前退出旧应用并保留配置、课程输出及模型缓存；替换完整应用包。2.0 的任务和笔记版本历史无法由 1.x 管理。
- RC1 前的 macOS 原生审查覆盖受控在线视频、本地视频、Apple 1.7B 识别、AI 成功和失败恢复、暂停与重启、阅读、导出、首次引导和存储恢复。桌面本机回归为 **223 项通过、3 项忽略**；发布流程另执行三个平台的桌面 release 测试及打包检查。
- Windows/Linux 原生视觉、其他硬件的识别、真实第三方服务和账号网络组合，以及长时间高负载使用仍需进一步试用。上述 macOS 结果不代表所有平台和场景均已验证。
- 逐页审查、独立复核及具体边界见 [完整审查记录](https://github.com/mizorewww/course2md/blob/v2.0.0-rc.1/docs/UX-PRODUCT-AUDIT-2026-09-09.md)。

启动后在「设置 → 应用」确认版本 `2.0.0-rc.1`；CLI 使用 `--version` 确认。反馈问题时请附系统、版本、复现步骤和已脱敏的诊断信息。

## English

**2.0 RC1** simplifies conversion into one start action followed by direct reading. It adds a four-step setup flow, clearer settings and model preparation, scoped recovery for partial results, improved search and image viewing, and fixes macOS redraw and drawable lifecycle issues. Background completion respects the page or image viewer currently in use.

Use the platform assets above or the independent Homebrew `course2md-gui@rc` and `course2md-rc` channels. Stable packages remain unchanged. Native walkthrough evidence is from macOS; Windows/Linux visuals, other recognition hardware, live third-party services and sustained-load scenarios still need broader testing.
