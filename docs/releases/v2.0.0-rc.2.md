# v2.0.0-rc.2：更顺滑的界面与精简的 2.0 基础

这是 **2.0 的第二个候选发布版（RC2）**。本版不改变工作流程和界面外观，集中提升桌面端的滚动与响应速度、引擎处理效率，并移出 2.0 中不再需要的 1.x 兼容代码。GitHub Latest、默认 Homebrew 包和 AUR 稳定包继续提供稳定版；试用 RC2 请使用本页附件或独立 RC 通道。

## 相比 RC1

- **界面响应**：阅读器、任务列表和课程库改为只渲染可见区域；工作区写入、阅读位置保存与重绘合并，长笔记滚动、查找跳转和大型课程库切换更顺滑。
- **转换效率**：引擎复用 LLM 连接，音频切分与识别双缓冲，长音频内存占用大幅降低，产物复制和恢复校验并行，在线视频每次运行只探测一次。输出与行为不变。
- **CLI 反馈**：场景扫描显示预计总帧数；字幕阶段和转写剩余时间可见；`models inspect` / `models prepare` 输出人类可读摘要；`summarize --quiet` 生效。
- **CLI 中英文完整**：已有 `config.toml` 但尚未配置服务时，首次运行向导也会触发；补齐其余中文/英文提示。
- **精简遗留兼容**：移除 1.x 笔记导入、旧 `config.toml` 迁移界面和旧工作区状态迁移。旧版本产生的文件不再静默迁移，改为保留原文件并重置到当前格式；同时移除 `OPENROUTER_API_KEY` 环境变量回退和 `@alpha` Homebrew 别名。
- **测试与文档**：合并冗余测试，CI 在三个平台运行集成套件；精简一次性评审记录，重写中英文 README、开发与打包文档。

## 下载桌面应用

GUI 包含同版本 CLI 引擎，无需另装 CLI。

| 平台 | 安装包 | 使用方式 |
| --- | --- | --- |
| macOS Apple Silicon，macOS 15+ | [DMG](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.2/course2md-gui-macos-arm64.dmg) | 退出旧应用，将完整 `course2md.app` 放入「应用程序」 |
| Windows x64 | [桌面 ZIP](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.2/course2md-desktop-windows-AMD64.zip) | 完整解压，打开 `course2md-desktop.exe`，保留同目录的引擎 |
| Linux x64 | [桌面 tar.gz](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.2/course2md-desktop-linux-x86_64.tar.gz) | 完整解压，运行 `./course2md-desktop`；预编译包基于 Ubuntu 24.04 |

处理视频需要 ffmpeg/ffprobe，在线视频还需要 yt-dlp。Homebrew 会安装这些依赖；手动安装请参阅 [安装指南](https://github.com/mizorewww/course2md/wiki)。Intel Mac 和 Linux ARM64 提供独立 CLI，暂不提供预编译 GUI。

## Homebrew RC 通道

首次安装：

```sh
brew update
brew install --cask mizorewww/tap/course2md-gui@rc
```

已有稳定版或 alpha/RC1 的用户，先退出应用，再卸载原 cask（`course2md-gui`、`course2md-gui@alpha` 或旧 RC），然后安装 RC cask。卸载时不要加 `--zap`，以保留用户数据。手动安装过的应用可先移出「应用程序」留作备份。

后续更新使用 `brew upgrade --cask course2md-gui@rc`。独立 CLI 也有 RC 通道，默认不替换终端中的稳定版命令：

```sh
brew install mizorewww/tap/course2md-rc
"$(brew --prefix course2md-rc)/bin/course2md" --version
```

独立 CLI 附件覆盖 macOS ARM64/x86_64、Linux ARM64/x86_64 和 Windows x64。手动安装 Apple Silicon CLI 时，还需下载本页 `mlx-macos-arm64.metallib`，改名为 `mlx.metallib` 并放在 CLI 同一目录；Unix 可执行文件需赋予执行权限。

## 升级与验证范围

- 从 RC1 升级可直接覆盖安装，保留配置、课程输出及模型缓存。1.x 笔记导入已移除；2.0 的任务和笔记版本历史无法由 1.x 管理，旧格式文件按保留并重置处理。
- 本版改动经桌面本机回归验证（课程库、阅读器滚动与目录跟踪、任务列表渲染在虚拟化前后一致），三个平台的桌面 release 测试、打包检查与 CLI 构建由发布流程执行。
- Windows/Linux 原生视觉、其他硬件的识别、真实第三方服务和账号网络组合，以及长时间高负载使用仍需进一步试用；macOS 的验证结果不代表所有平台和场景均已覆盖。

启动后在「设置 → 应用」确认版本 `2.0.0-rc.2`；CLI 使用 `--version` 确认。反馈问题时请附系统、版本、复现步骤和已脱敏的诊断信息。

## English

**2.0 RC2** focuses on responsiveness and cleanup rather than new flows: the reader, task list and course library now render only visible rows, workspace writes and repaints are coalesced, and the engine reuses LLM connections, double-buffers audio cutting against inference, and streams long-audio analysis with a much lower memory peak. The CLI reports an estimated frame total during scene scanning plus subtitle-stage and transcription ETAs, and completes the remaining bilingual messages.

Legacy 1.x note import, the old `config.toml` migration UI and old workspace-state migrations were removed; files from older builds now take the preserved-and-reset recovery path instead of silent migration. The `OPENROUTER_API_KEY` environment fallback and `@alpha` Homebrew aliases are gone as well. Output and everyday behavior are unchanged.

Use the platform assets above or the independent Homebrew `course2md-gui@rc` and `course2md-rc` channels. Stable packages remain unchanged. macOS was verified against the running app; Windows/Linux visuals, other recognition hardware, live third-party services and sustained-load scenarios still need broader testing.
