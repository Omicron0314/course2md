# v2.0.0-rc.4：全仓工程审计加固，macOS GPU 识别修复，设计系统终审通过

这是 **2.0 的第四个候选发布版（RC4）**。本版以一次覆盖引擎、CLI、桌面端与原生模块的全仓工程审计为主线：修复 macOS 上 GPU 不被正确识别的三层根因，消除两个可冻结整个桌面界面的高危缺陷，并把排版、动效与信息展示统一进共享设计原语——全部改动经独立 subagent 对运行中原生应用的六轮截图评审，最终判定通过。GitHub Latest、默认 Homebrew 包和 AUR 稳定包继续提供稳定版；试用 RC4 请使用本页附件或独立 RC 通道。

## 相比 RC3

- **macOS GPU 识别修复**：`doctor` 不再把 BLAS/Accelerate 等 CPU 后端误报为 GPU 设备（引擎与桌面共享同一份设备白名单）；桌面端环境探测给 llama 设备枚举与引擎相同的超时预算（实测 Metal 枚举可达十余秒，原 5 秒预算导致误判）；设置中的本机引擎选择可靠持久化。真机（Apple M3 Max）验证：doctor 输出 `GPU MTL0: Apple M3 Max`，设置页显示并保持「GPU」。
- **两个可冻结整个界面的高危缺陷**：
  - 任务启动时在主线程同步读取钥匙串；当系统授权弹窗队列被其他应用占用时，调度器、点击与渲染全部无限期冻结。现先在专用线程解析凭据再回 UI 线程启动。
  - GPUI 后台 executor 任务可能经 GCD queue override 跑上主线程——所有阻塞调用（钥匙串、受限 HTTP、子进程探测、数 GB 模型文件的校验、课程库迁移扫描等）统一改走专用 OS 线程（`spawn_blocking_io`）。
- **任务可靠性**：作业监视器不再因子进程输出管道未关闭而永久卡住任务槽（有界等待后必定推进状态）；取消覆盖补齐到 ASR 服务启动、视频下载、AI 校对与截图/转写联合中止；确定性错误不再无意义重试；AI 校对全程可取消且正确统计跳过分片。
- **设计系统统一**：新建/任务/笔记库/结果共享同一内容标尺；同级选择控件统一为「共享轨道 + 移动选中态」并在页面底色上也有定义；ⓘ 信息图标纪律统一（不再用对象图标冒充）；状态徽章表达「部分内容待补全」「准备中」等真实状态；页标题统一为图标+半粗标签槽。
- **阅读器**：章节标题只在每章首次出现；「从此处观看」贴着它作用的截图；目录条目单行截断；macOS「始终显示滚动条」偏好在正文、设置、引导与编辑器中一致兑现；行内截图限高，摘要与正文在默认窗口内衔接。
- **信息展示**：模型下载在设置、引导与任务进度中统一为 250ms 节拍、实测速度与预计剩余；下载可暂停、可恢复（已下载部分保留复用）；任务「部分完成」终态给出具体原因与分级恢复动作（修复并补做/生成新版）。
- **动效**：进入/落定/值变化/调色板切换时长全部收敛到契约范围并集中命名；「减少动态效果」开关即时生效。
- **其他**：install.sh 收尾提示在 `set -u` 下中断的问题；发布打包对损坏产物直接失败；最低系统版本对齐。

## 下载桌面应用

GUI 包含同版本 CLI 引擎，无需另装 CLI。

| 平台 | 安装包 | 使用方式 |
| --- | --- | --- |
| macOS Apple Silicon，macOS 15+ | [DMG](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.4/course2md-gui-macos-arm64.dmg) | 退出旧应用，将完整 `course2md.app` 放入「应用程序」 |
| Windows x64 | [桌面 ZIP](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.4/course2md-desktop-windows-AMD64.zip) | 完整解压，打开 `course2md-desktop.exe`，保留同目录的引擎 |
| Linux x64 | [桌面 tar.gz](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.4/course2md-desktop-linux-x86_64.tar.gz) | 完整解压，运行 `./course2md-desktop`；预编译包基于 Ubuntu 24.04 |

处理视频需要 ffmpeg/ffprobe，在线视频还需要 yt-dlp。Homebrew 会安装这些依赖；手动安装请参阅 [安装指南](https://github.com/mizorewww/course2md/wiki)。Intel Mac 和 Linux ARM64 提供独立 CLI，暂不提供预编译 GUI。

## Homebrew RC 通道

首次安装：

```sh
brew update
brew install --cask mizorewww/tap/course2md-gui@rc
```

已有稳定版或 alpha/旧 RC 的用户，先退出应用，再卸载原 cask（`course2md-gui`、`course2md-gui@alpha` 或旧 RC），然后安装 RC cask。卸载时不要加 `--zap`，以保留用户数据。手动安装过的应用可先移出「应用程序」留作备份。

后续更新使用 `brew upgrade --cask course2md-gui@rc`。独立 CLI 也有 RC 通道，默认不替换终端中的稳定版命令：

```sh
brew install mizorewww/tap/course2md-rc
"$(brew --prefix course2md-rc)/bin/course2md" --version
```

独立 CLI 附件覆盖 macOS ARM64/x86_64、Linux ARM64/x86_64 和 Windows x64。手动安装 Apple Silicon CLI 时，还需下载本页 `mlx-macos-arm64.metallib`，改名为 `mlx.metallib` 并放在 CLI 同一目录；Unix 可执行文件需赋予执行权限。

## 升级与验证范围

- 从 RC3 升级可直接覆盖安装，保留配置、课程输出及模型缓存。首次打开时桌面端会按新的凭据解析路径工作；若系统弹出钥匙串授权，请选择「允许」。
- 本版改动经 macOS 本机回归验证：引擎 135 项、桌面 225 项测试全部通过，项目自有代码 clippy 无告警；任务调度与转换链路在真实视频上完成端到端验证（含 AI 服务失败时的优雅降级与恢复入口）；设计改动经独立评审子代理对运行中原生应用的六轮截图评审（184 张），终审判定通过。
- Windows/Linux 原生视觉、其他硬件的识别、真实第三方服务和账号网络组合，以及长时间高负载使用仍需进一步试用；macOS 的验证结果不代表所有平台和场景均已覆盖。

启动后在「设置 → 应用」确认版本 `2.0.0-rc.4`；CLI 使用 `--version` 确认。反馈问题时请附系统、版本、复现步骤和已脱敏的诊断信息。

## English

**2.0 RC4** is a hardening release driven by a full-repository engineering audit. On macOS, GPU recognition is fixed at three layers (doctor no longer reports BLAS/Accelerate CPU backends as GPU, the desktop probe now shares the engine's device-enumeration timeout, and the engine selection persists reliably). Two high-severity freezes are gone: task credentials no longer resolve synchronously on the UI thread while a keychain prompt is queued behind another app, and every blocking call (keychain, bounded HTTP, subprocess probes, multi-GB model digests, library migrations) moved to dedicated OS threads because GCD may run background-queue tasks on the main thread. Task cancellation now covers ASR startup, video downloads, AI proofreading and screenshot/transcription jointly, and a bounded job-monitor drain guarantees exit events propagate. The desktop's typography, peer-selection controls, status badges, motion timings and download/pause/resume information were consolidated into shared primitives and verified through six rounds of independent screenshot review of the running native app, ending in a passing final verdict.

Use the platform assets above or the independent Homebrew `course2md-gui@rc` and `course2md-rc` channels. Stable packages remain unchanged. Verified on macOS (135 engine + 225 desktop tests, zero project clippy warnings, real end-to-end conversion); Windows/Linux visuals, other recognition hardware, live third-party services and sustained-load scenarios still need broader testing.
