The one onboarding caller that bypassed the adapter was wrapped after separate root authorization. Checked state, disabled state, callbacks, FocusRing, BaseSwitch semantics and the existing spring remain in their original paths; page padding was not altered.

The patch was generated from and replayed against the locked local source using `sources.py --locked`; the generated switch exactly matched the formatted reference. Rustfmt parsing/formatting and whitespace diff checks passed. This reviewer did not run Cargo, GUI or commit. The root reported 197 passed / 3 ignored after the wrapper/dependency change, before the final onboarding caller was added; the final combined build and **new native switch geometry evidence are still pending**. Because this reviewer implemented the correction, the root should also inspect its new native result independently before closing S10-01.
