## P2：服务卡没有直说默认仍使用旧配置

`v4-settings-services` 最新资源名为“恢复校对服务”，模型 fixture-summary，显示校对／摘要通过；描述却只说“本次调整未设为默认”。同轮选择器证明默认仍在旧配置 v3、fixture-model。“本次调整”是长期列表里无上下文的动作历史，读者可能把最新卡片的通过误认为当前生成默认已经修好。

只读源码确认该文案的条件正是“同一 service identity，但 defaults 绑定旧版本”。主代理已采纳，授权修为：

- 同一服务仍绑定旧版：`默认仍使用旧配置 v{number} · {model}`，值取真实 defaults 版本。
- 当前显示版本就是默认：`默认服务`。
- 其它服务 identity 或没有默认：`未设为默认`。

此处仅更改显示，没有更新绑定或改变已提交任务。diff-check 通过；**v4 旧观察保留，修正等待 v5 原生复拍**。

## P3：无需认证失败时可更直接指向认证方式

401 图明确选择“无需认证”，错误却只叫用户“检查 API Key 或模型权限”。短原因已解决不可见问题，但此时页面没有 Key 输入框。可按当前认证方式把恢复方向说得更直接，例如“服务要求认证，请检查认证方式或模型权限”；有 Key 时继续提示检查 Key。此为行动指向的小幅改进，不把所有 401 强行解释成同一种服务规则，也不据此阻止普通保存。当前未修改。
