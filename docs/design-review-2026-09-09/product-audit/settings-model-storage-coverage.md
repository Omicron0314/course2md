## 只有源码或自动测试支持的关键行为

- 本机引擎显式选择经过在线往返和偏好重载保持：存在 `local_engine_choice_survives_online_service_and_restart`；flow 曾报告该测试通过。这里没有重演原生 CPU → 在线 → 本机 → 重启，故不写原生通过。
- 修复阻止规则匹配真实配置指纹，名称变化和无关测试能力切换不清除明确拒绝；401／403 配置拒绝与 429／5xx 临时失败分开。`settings-refusal-tests.log` 明确记录 8 个 `service_test` 定向测试通过，其中含拒绝范围、重试状态、返回结构和取消前不发送。该日志是逻辑测试，不是点击修复弹窗的证据。
- `settings-save-only-test.log` 明确记录 `explicit_test_refusal_still_allows_save_only_without_changing_defaults` 通过；任务私有服务“仅保存”保留、不改变默认这一行为有数据层回归。最终弹窗保存／取消／补做连贯流程仍待原生。
- 模型发现字段已合并输入与选择／刷新动作，允许手填且不自动选第一项，并保留异步结果匹配保护。编译或自动测试不能代替加载、空列表、失败、手填和取消的真实交互。
- 设置保存失败的固定恢复区、存储每项的局部错误与恢复逻辑已经修改。当前覆盖清单没有本轮最终版保存失败原图，不能据正常页无错误作关闭。

## 必须再运行的关键项（按影响排序）

1. **任务修复中的明确拒绝与保存范围。** 从真实 partial 任务进入服务修复，收到 401／403 后，不改配置应就近看到能力与短原因、不能直接补做；只改名称／切换测试能力不能绕过。点击“仅保存”应保存私有配置而不新建任务、不改默认。修正实际字段后重试成功，再开始补做应只处理缺失组件且绑定新配置。另用 429 或 5xx 确认临时失败没有被同样硬锁死。普通设置仍应允许未通过测试的保存。
2. **真实自动导出的闭环。** 勾选一种自动格式，完成生成，按新说明在阅读页打开导出文件夹并定位正确版本文件；取消手动另存应保留自动文件与阅读状态。已有 v5“仅补 HTML → Finder”的闭环证明补做输出可取用，不能替代首次自动导出。主代理刚修改的说明与入口需复拍。
3. **模型需要处理的状态。** 用隔离缓存运行至少 Missing → 准备中 → 成功和一次失败／重试；补 Partial 与 Cached 未验证，确认每种状态的主结论、动作与数据发送说明相符。模型准备期间离开／返回设置不能重复启动，也不能把另一个活动模型写成默认模型。Loaded 维护层级已有 v5 证据，无须再次只拍这一健康状态。
4. **设置无法保存。** 隔离只读／写入失败 fixture 中改一个偏好，错误与恢复动作需常驻可见；重试成功才宣称已保存，重启核对实际值。服务编辑中测试结果已经收到但写入失败时，也应保留已收到结果而诚实报告未保存。
5. **存储错误和迁移。** 在临时库执行新增／默认切换、迁移取消与迁移成功，再用失联路径确认局部错误、重新关联／重试不会误指别的库。核对迁移后原笔记仍能读、输出入口指向新位置；失败不应消失已有记录。正常 v5 两库静态页没有覆盖这些操作。
6. **选择权、停用和异步字段。** 原生 CPU／自动 → 在线 → 本机并重启保留；长服务菜单中的旧绑定不自动升级、停用项不能新选。模型发现加载时修改端点／关闭编辑器，迟到响应不能改新字段；空列表／失败仍能手填并保存。
7. **最终共享控件的极端布局。** 至少窄窗 200% 的生成页长服务及菜单、服务编辑失败固定区、存储长路径；另复核正常宽窗。已有十主题外观页不是这些复杂内容的覆盖。选中控件的悬停／按下／普通键盘焦点、滚动条活动／静止与减少动态效果需实际过程或录制，不用静态 switch 值代替。

已登录账号、扫码等待／过期、服务截图／语音测试失败、无服务且 AI 开关组合、默认服务停用后恢复、多格式部分导出、缓存打开失败、跟随系统明暗切换、异常关闭后恢复均尚未在我持有的最新原生证据中访问。若主代理已有独立过程记录，应在最终报告按具体状态补证，不将本表未知一并改成通过。
