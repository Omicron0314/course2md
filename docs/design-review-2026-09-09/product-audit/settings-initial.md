## 主要判断

当前设置页的问题是信息与操作缺乏共同的布局单位。每个标签、胶囊、说明条、状态和操作在局部都能摆下，但整页同时存在全宽信息条、有限宽度控件、另起一行的关联动作和第三套诊断表格。用户必须靠文字重新判断关系。继续只调 padding 或把按钮挪到标注位置，不能解决这个问题。

共享规则需要允许变化：`settings_form_row` 固定 200px 标签列、320px 控件 basis、560px 控件上限，又把每条 hint 单独绘成全宽 `info_callout`（settings_ui.rs:264）。这套实现本身就是六张截图中割裂感的来源。“可选说明统一用信息面板”不能演变成“每个设置项都有一个横贯页面的框”。“普通分组不加卡片”的要求也不应阻止对独立模型缓存、服务、存储位置使用有意义的实体容器。应共享关系与语义，而不是把所有页面强制做成同一种形状。

## 内容与操作分组方案

| 页面 | 首屏应回答的问题与分组 | 保留的必要信息 | 删除或下收的信息 |
| --- | --- | --- | --- |
| 外观 | 外观模式 → 当前浅/深配色预览 → 界面偏好 | 模式、两个独立保存值、即时效果/保存失败、字号与动态设置 | 重复解释标准控件的说明；与真实选项无关的装饰分组 |
| 生成笔记 | 文字来源 → 本机/在线识别及当前模型 → AI 处理及服务 → 导出/离线文件 | 默认影响范围、字幕语言、明确固定选择、AI 发送对象、导出格式、视频占用空间 | 每行一个框的帮助；硬件细节、仓库 ID、标准 prompt 全文移入对应详情 |
| 服务与账号 | 账号身份和状态 → 语音服务集合 → AI 服务集合 | 已登录身份/失效状态、服务名和模型、默认标记、能力失败、关联操作 | “连接你使用的来源账号、语音或 AI 服务”这种不增加决策的信息条；常驻多日期徽章 |
| 服务编辑 | 连接信息 → 模型 → 测试；固定取消/测试/保存 | 字段错误、已有密钥语义、请求地址、测试用途/计费说明、保存作用范围 | 环境变量来源等诊断说明下收；不要以测试成功冒充保存成功 |
| 存储 | 默认保存位置与其他位置 → 需要处理的位置 → 迁移与备份 | 可写/不可访问、完整路径、默认作用范围、移动与重新定位区别、保留备份后果 | 常驻库 ID、重复路径；技术详情按位置归属，不单独复制整份列表 |
| 应用 | 产品身份及链接 → 重访引导 → 运行检查；按需诊断 | 版本/构建、许可、修复能力缺失的入口、环境/模型区别 | 当前平台不适用的 NPU/Apple 条目；冗长模型 ID 与缓存文件明细不应成为主要阅读内容 |

对于标签与开关，优先使用同一设置单元的两端；单元整体的宽度应适合阅读和选项，而不是占满可用窗口。对于输入，使用顶置标签可以避免和模型获取/字段错误形成互不一致的“第二列”。对于实体列表，标题、内容和尾部操作有自己的稳定槽位。上述三种结构应各自成为共享角色，不应继续用一个万能 form-row 包装全部内容。

## 必须实际访问的原生状态

本次未访问这些状态，不能据源代码宣布验收。主代理应至少覆盖以下具体路径。

1. 五个设置分类在正常宽度、窄窗口、宽窗口的完整首屏；100%、125%、150%、200% 字号，检查“内容是否仍好读、关系是否清楚”，而不只检查不溢出。
2. 外观跟随系统/固定浅色/固定深色；两种配色弹层；十个配色；选择后的 hover/pressed/focus；保存失败、重试成功及重启保存值。
3. 生成设置的 AI 全关、只摘要、只校对、截图开/关；无服务、一个服务、多服务、已停用服务。选择和编辑应相邻，发送说明与当前选项一致。
4. 字幕语言自定义草稿、无效代码、应用与取消；自定义 prompt 很长、未应用、保存失败；当前任务覆盖与默认设置交叉修改后回到原任务。
5. 自动/本机/在线识别，受支持/不支持的显式模型；首次缺失、部分下载、已下载未加载、已加载、缓存检查失败。
6. 模型准备开始、真实进度、暂停、继续、失败、完成；准备中切换所选模型/分类，确认原操作可找回且状态不会归到另一个模型。
7. 运行检查正常、检查中、程序缺失、模型未准备、设备不可用；展开程序/模型/缓存/设备详情，尤其长仓库名与路径。不能把运行时可用视作模型已加载。
8. 服务添加/编辑/取消/保存；字段缺失、模型获取进行中、空列表、失败、长列表；模型列表请求中修改地址或关闭编辑器后晚响应。
9. 服务测试尚未发送、进行中、通过、未通过、结果未知；分别测试校对/摘要/截图；原生确认测试后果一直与动作共现，测试成功不隐藏保存步骤，列表入口不直接发送请求。
10. 服务保存失败、测试结果持久化失败、本次绑定失败；停用默认服务及停用后已有任务的恢复入口；取消编辑不更改正在使用的服务。
11. 账号未登录、验证中、已登录、登录失效、暂时无法验证；取消登录与失败后返回来源任务，已有输入保留。
12. 存储健康、加载、部分离线、全部不可访问、关联丢失、路径移动、登记重复；错误/动作是否仍属于具体位置。
13. 隔离 fixture 中移动课程库的确认、复制、取消、继续、失败、完成与旧位置备份清理；不要用真实数据来完成破坏性验证。
14. 设置保存错误发生在滚动底部、切换分类后、技术详情展开后；确认简明错误/重试始终可发现，原选择不被悄悄复原。
15. 从笔记、工作台修复入口、处理中任务临时进入设置再返回；原读写位置和任务输入保留，后台完成不抢走设置所在页。
