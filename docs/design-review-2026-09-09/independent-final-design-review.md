# 独立设计审查：本轮原生设置与关联状态

日期：2026-09-09。审查依据为用户本轮七张原始拒绝图，以及当前 `course2md-design/SKILL.md`、`references/system.md`、`references/settings.md`。本记录不沿用前轮验收结论，不以测试数量、时长常量或文件命名代替证据。

## 判断

当前可见设置页面已经形成共同的结构：固定导航、明确的内容分组、统一的标签与控件列，以及靠近对象的状态和操作。原图中重复类别标题、散布在卡片各角落的关于信息、远离标签的运行状态、变长主题网格牵动其他设置等主要问题，在新画面中有对应解决。当前不需要再重做整页结构。

这不构成全产品或全部状态通过。200% 顶栏标签截断、失败时“完成”压过“重试”的优先级，以及空服务表单缺少格式线索，均在本次审查中发现；修正后的原生画面仍需补齐。图 61 的刷新独占一行是新增的工具栏密度问题。

## 动效源码检查

- `views.rs` 的整页重入淡入和 `settings_ui.rs` 的类别重入淡入已移除；没有再将导航指示移动与整页淡入绑定。
- 共享选择器使用稳定 ID 的 `selection_value`，文字位置固定，指示面移动。当前源码的选择曲线为 180ms 平滑起止；该常量不是视觉通过证据。
- 主题实际颜色插值保留约 280ms，卡片选中边框/底色/勾选使用共享 value。它们都说明同一选择的结果，但是否在感知上协调，仍需要实际过程观察。
- 主题选择器的卡片集合由浅/深种类决定；选择具体主题不重建不同数量的页面卡片。页面只有两张稳定预设卡。
- 保存错误、测试结果和手动展开详情仍有局部反馈。源码未见模式或预设选择额外触发整页重入淡入；减少动态效果仍走直接终态路径。
