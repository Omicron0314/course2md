# 课程流程与错误恢复复审

继续上一轮设置复审，覆盖课程读取、文件夹、添加来源和错误恢复。依据 [桌面设计约定](DESKTOP-DESIGN-SYSTEM.md)；验收范围包含任何有证据的设计问题。

## 修改

- 文件夹元数据读取失败不再阻止展示完好的课程。未知归属单独标明，组织操作暂不可用；恢复元数据后可以重新读取。
- 笔记读取使用独立请求代次，后续导航或新阅读请求会使旧结果失效。读取反馈不再借用课程库刷新状态。
- 根据当前页面和弹窗实际可见的输入框清理隐藏焦点，覆盖链接模式切换、课程搜索及文件夹编辑。
- 空链接和格式错误在输入旁校验，保留“预览课程”动作；只有真正的预览请求失败才提供重试语义。
- 文件夹名称校验就地显示，编辑、取消、重开和成功后清除旧错误。新建和重命名分别使用“创建文件夹”“保存名称”。
- 系统名称“未分类”不再允许新建或改名占用；已存在的旧同名记录继续可读可改，不迁移或删除原课程。

## 验证方法

由独立子代理通过 Computer Use 操作实际 macOS 应用。使用隔离配置及既有真实视频转换结果的副本；不触碰日常课程目录。自动化工具的陈旧画面、焦点路由异常不能直接认定为产品问题，不能据此宣称验收通过。

两项新增持久化回归测试验证拒绝修改时文件字节及归属不变、旧记录可加载和重命名。未添加模拟成功的脚手架测试。

## 实机复验

- Flow R1：真实课程文稿和导出文件页可读；新建保留名称被拒绝，正常文件夹可创建。确认文件夹全局错误条会在取消后残留，随后改成独立字段错误。
- 损坏恢复：备份隔离库组织信息后写入无效内容，子代理刷新确认全部课程仍显示、笔记可打开、未知归属禁用；恢复原字节后重新读取，文件夹与归属恢复且警告消失。
- Flow R2：文件夹错误就地显示，取消/重开清除旧提示；搜索与刷新高度一致；来源模式切换后隐藏字段没有接收测试字符。空值和非法链接保持“预览课程”并显示中文字段错误。
- 系统文件选择器：旧实例曾显示无法确认文件，但伴随自动化陈旧画面。R2使用实际系统选择器成功选中既有 lesson.mp4 并读取12秒视频预览，不为工具异常添加产品绕过代码。

- Flow R2 真实任务：通过系统选择器导入 lesson.mp4，字幕优先完成笔记；仅语音模式因无音轨真实失败，调整为字幕优先后完成。失败过程中发现原始 ffmpeg 错误以蓝色横幅越界显示，转换偏好也仍使用旧复选框，随后修复。
- Flow R3：封面边界、更换视频对齐、统一开关及可中断展开/收起通过实际操作检查。无音轨失败显示简短中文建议，原始输出默认折叠，展开为纯文本且无横向越界；重试再次完成。10分钟 stt-long.mp4 也完成 Apple 本机转写，实际观察到音频与画面并行及转写状态；工具未捕捉到中途数值 ETA，因此不将数值 ETA 计为本轮实机通过。
- 补充状态修复：无日志提前退出不再误显示“暂无任务”；无日志时不提供空日志区域。阶段按处理顺序排列，任务详情不重复显示底栏摘要。AI 配置缺失时先提供配置入口并阻止无效任务，往返设置保留课程预览和本次转换选项。
- Flow R4：仅字幕、HTML-only、本次 AI 开启的草稿，先被缺失服务配置拦截；经配置入口保存测试地址（未发送请求）后返回，预览和全部本次选项保持，配置提示消失。随后关闭 AI 继续本地验收。
- Flow R4 结束：中文错误、日志换行与折叠、处理阶段顺序、字幕优先重试再次通过；HTML-only 结果进入文件页。测试服务地址与模型已清空，默认及本次 AI 均关闭。子代理未发现新的具体设计问题。

- Flow R5（729f384）：子代理通过“完整诊断”运行真实 Doctor 任务，确认日志折叠为向下箭头且正文隐藏，展开为向上箭头及“收起日志”，正文与复制入口可见，无越界。本轮发现的具体设计问题均已关闭。

## 验证范围与限制

桌面测试 12 项通过，2 项显式忽略；Clippy 禁止警告检查通过。本机 macOS 开发包通过签名与磁盘映像校验。一次 Swift 增量构建停滞，经停止本轮构建子进程并正常重试恢复，未添加构建绕过代码。

实机操作仅在 macOS 完成。笔记读取速度较快，未强制复现异步读取乱序；请求代次及导航判断由独立代码审查确认。未强制制造零输出退出，也未捕捉到长任务中途的数值 ETA 或最终版本运行时底栏画面，因此不声称这些分支已完成逐帧实机验证。它们分别由状态分支审查、既有速率/ETA 测试和渲染条件复核补充。
